# 新CPUキャラクター6人の試験と暫定定義

2026-10-11。新しいCPU方針を**既存の5,184キャラクターの判断に依存させず**、公開情報だけから行動を選ぶ試作品として実装した。6種類の打ち方と山札推測3段階の計18条件を試し、そこから [`cpu_characters_experimental.json`](cpu_characters_experimental.json) の6人を定義した。これは試験用の名簿であり、Unity/WebGLや通常のPython対局のCPUにはまだ導入していない。元データの集計値、信頼区間、シード、設定は [`cpu_character_results.json`](cpu_character_results.json) に保存した。

## キャラクター

- **慎重な帳簿係**（堅実・推測0）：完成できなかったときの損失を強く嫌う。特殊行動のダブルも使わない。比較的弱い相手として残す。
- **港の仲買人**（均衡・推測1）：得点・完成見込み・手番コストを均衡させる。両人数のリーグで強い。
- **早足の商人**（速攻・推測2）：完成までに要る手番を重く見て、小さめのノルマを多く選ぶ。3人戦のリーグでは首位。
- **勝負師の船長**（逆転・推測2）：高得点ノルマの上振れを重く見る。ノルマ10〜13の選択割合は6人で最も高い。
- **目ざとい競売人**（妨害・推測1）：相手と競合する商品を優先する。相手のノルマと同じ種類を選んだ割合は、3人戦32.2%、4人戦46.4%で、ほかの5人より高い。実力はやや低めだが打ち方が明確に違う。
- **品揃えの収集家**（称号・推測1）：無理なく成立しそうな称号へ重みを付ける。3人戦リーグでは生粋の買い付け・単色達成の成立回数が最多だった。

推測0は現在の場札と固定的な山札構成の事前比率を使い、公開済み札を数えない。推測1は場・捨て札・各人の公開札を数え、伏せた8枚を未知として概算する。推測2はそれに加え、配り直しで場から山札に戻った札を**種類ごとの期待量**として覚える。物理カードIDから同じ見た目の2枚を見分けたり、非公開の山札・除外札を読んだりしない。いずれも厳密な完成確率ではなく、候補を比べるための近似である。

## どのように試したか

1. [`cpu_character_simulator.py`](../tools/cpu_character_simulator.py) で18条件を、旧CPUキャラクターを相手にスクリーニングした。3人戦・3ラウンドは60配り×全3席、4人戦・4ラウンドは40配り×全4席。各候補について対照と同じ初期シード・旧CPU構成・候補席から始める。行動が分岐した後のゲーム展開が一致するという意味ではない。
2. 6人を選んで [`cpu_character_league.py`](../tools/cpu_character_league.py) で**新CPU同士**を対戦させた。3人戦は6人から3人を選ぶ全20組、4人戦は4人を選ぶ全15組。各組12配りで全員を各席へ順に置いた。各人数で720対局。
3. 得点・1位の取り分・称号成立数・ノルマの大きさ・競合札の選択率を比べた。強さの上位だけを残さず、行動上の特徴と強弱の幅を優先して6人にした。

推測2と推測0の**同じ打ち方同士**の得点差は、3人戦で平均＋6.32〜＋14.44点、4人戦で＋5.71〜＋9.31点。各打ち方の配り単位95%近似区間の下限は、今回の条件ではすべて0を超えた。推測1→2は単調に改善しない組合せもあり、推測レベルだけで難度を確定しない。

リーグ戦の1位取り分は次の通り（3人戦／4人戦）。港の仲買人 **0.399／0.342**、早足の商人 **0.404／0.293**、勝負師の船長 **0.332／0.292**、品揃えの収集家 **0.331／0.276**、目ざとい競売人 **0.282／0.166**、慎重な帳簿係 **0.253／0.132**。無作為な同程度の3人・4人戦での目安はそれぞれ1/3・1/4。全員が毎回同じ組で戦ったわけではないので、この値を普遍的な強さの順位とはしない。区間と相手構成は結果JSONを参照する。

## 再実行

```bash
python3 tools/cpu_character_simulator.py --deals 60 --players 3 --rounds 3 \
  --seed 20261011 --json-out /tmp/quota-characters-3p.json
python3 tools/cpu_character_simulator.py --deals 40 --players 4 --rounds 4 \
  --seed 20261012 --json-out /tmp/quota-characters-4p.json
python3 tools/cpu_character_league.py --roster docs/cpu_characters_experimental.json \
  --players 3 --rounds 3 --deals-per-cast 12 --seed 20261013 \
  --json-out /tmp/quota-league-3p.json
python3 tools/cpu_character_league.py --roster docs/cpu_characters_experimental.json \
  --players 4 --rounds 4 --deals-per-cast 12 --seed 20261014 \
  --json-out /tmp/quota-league-4p.json
```

名簿の `id` は試験内の識別子で、既存の5,184キャラクターIDとは独立。今後ゲーム本体へ採用する場合は Python と Unity の判断を同条件で合わせ、名称・ID・旧ランキングの扱いを別に移行する。現行の近似には、相手の行動予測、生粋・五種を狙う意図の推定、個別の数字ごとの正確な山札事後分布、多手先読みを含まない。得点ルールを変える場合は、この成績を流用せず新ルールで再評価する。
