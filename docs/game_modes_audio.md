# ゲームモードとラウンドBGM

## ゲームモード

スタート画面の名前欄の上で選ぶ。選択は端末の `PlayerPrefs` に保存する。

- **オフライン**: この端末内のゲームエンジンが対局を進める。人間は1人で、残りはCPU。卓一覧と通信は使わず、観戦・通信タイムアウトの設定も出さない。
- オフラインのロビーには「CPU模擬戦を見る」を設ける。選ぶと人間プレイヤーなしでCPU同士の対局を開始し、観戦できる。
- **インターネット通信**: 卓・行動・CPU処理はサーバーが管理する。WebGLでは、Webアプリを開いたURLのオリジン（スキーム、ホスト、ポート）に `/api/` を送る。Unity EditorなどURLのない環境は、`QUOTA_SERVER_URL` 環境変数を指定すればその接続先だけを使う。未指定なら、同じマシンの `http://127.0.0.1:8080` を優先し、接続できなければ `http://133.88.122.153` を使う。Unity Editorと `http://192.168.0.10:8080` を開いたブラウザは、8080番のサーバーがそのマシンで動いていれば同じ卓を見る。サーバーが別のマシンにある場合は `QUOTA_SERVER_URL=http://192.168.0.10:8080` を指定してEditorを起動する。
- **ローカル通信**: 選択肢には「準備中」と表示する。現段階では選べない。ブラウザ内のUnity WebGLアプリがLAN向けHTTPサーバーになることはできない。将来、ネイティブアプリでホスト機能を実装するか、LAN内の別プロセスをサーバーにする方式を検討する。

## ラウンドBGM

原音源は `sound/play_bgm_02.mp3`。WebGL版はこのMP3を読み込んで音声バッファ内の16秒から92秒を直接ループする。Unity Editorなどのネイティブ版で使うクリップは `unity/Assets/Resources/QuotaBgm/intro.ogg`（0:00〜0:16）と `loop.ogg`（0:16〜1:32）である。ネイティブ版ではループ用クリップを読み込み時にPCMへ展開し、圧縮音声の再始動による隙間を避ける。そのためクライアントの音声メモリ使用量は増える。次のコマンドで原音源から再生成できる。

```bash
ffmpeg -i sound/play_bgm_02.mp3 -ss 0 -t 16 -c:a libvorbis -q:a 5 unity/Assets/Resources/QuotaBgm/intro.ogg
ffmpeg -i sound/play_bgm_02.mp3 -ss 16 -t 76 -c:a libvorbis -q:a 5 unity/Assets/Resources/QuotaBgm/loop.ogg
```

各ラウンドの開始時に冒頭を一度再生し、続けてループ区間を繰り返す。ラウンド終了、対局からの退出、スタート画面への遷移で停止する。Webブラウザの音声再生には、ブラウザ上でのタップやクリックが必要になる場合がある。

ロビーと対局中の「設定」で、個人設定として BGM音量とSE音量を0〜5の整数スライダーから選ぶ。0はOFF。値は端末の `PlayerPrefs` に保存する。BGMの変更は再生中にも適用する。SEは将来の効果音用に値を保存する。対局中の設定画面はゲーム進行や手番タイムアウトを止めない。

「五種の品揃え」はラウンド中に成立した時点で太字と左の○印で示す。その他の成立した称号はラウンド終了時、得点発表より前に同じ表示へ変える。この判定表示を1秒見せ、前半の0.5秒でBGMをフェードアウトし、続けてラウンド終了表示とボーナス計算を行う。

ラウンド終了パネルが最初に表示される瞬間、`sound/end_bgm_01.mp3` を一度だけ再生する。Unity版には `Resources/QuotaBgm/end.mp3` として同じ音源を収録する。ループはせず、個人設定のBGM音量（0〜5）を適用する。再生中に音量を変更した場合も反映する。曲の再生が終わる前に次のラウンドや最終終了へ進む際は、0.5秒かけてフェードアウトする。EXITによる退出では即停止する。終了済みの卓へ後から入った場合は再生しない。
