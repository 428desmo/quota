# Quota 軽量Web版（オフライン試作）

Unity/WebGL版から独立した、ビルド不要のHTML/CSS/JavaScript実装です。画像、音声、商品データは`web-lite/assets/`にコピーしてあり、Unity版のファイルを実行時に参照しません。対戦サーバーにも接続しません。

```sh
python3 -m http.server 8765 --directory web-lite
```

ブラウザで `http://127.0.0.1:8765/` を開きます。ローカルサーバーは静的ファイルを配るだけで、対局・CPU判断・得点計算はブラウザ内で行います。`file://` ではService WorkerとJSON読み込みを利用できないため、HTTPで開いてください。

初回にService Workerが約6MBのアプリ素材をバックグラウンドで保存します。インストール完了後は通信を切って再読み込みしてもオフライン対局を始められます。ブラウザによる保存領域の消去や容量不足には従います。

```sh
node --test web-lite/engine.test.mjs
```

現段階の対象は「1人＋CPU」対局です。基本ルール、特殊アクション、複数ラウンド、達成・連続・称号得点を移植しました。CPUキャラクターの名前とおおまかな傾向は引き継ぎましたが、Unity版の高度な山札推測や演出、オンライン対戦、細かな効果音同期は未移植です。同等性を高める次の段階では、共通シード・行動履歴による得点差分テストとCPU判断の詳細移植が必要です。
